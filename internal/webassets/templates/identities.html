Usage identities

Combine ccusage reports from multiple devices under one name. All locally recorded usage is included, including HTTP proxy requests. Each device has its own upload-only credential.

On each device, run npx codex-broker@latest install --broker-url https://YOUR-BROKER (Node.js 22 or newer), then enter the identity code at the hidden prompt. Replace the URL with your Broker address, including any root path; add --ca /path/to/broker-ca.pem for a private CA. Node is needed only for setup; syncing runs automatically in the background.

To upgrade, run npx codex-broker@latest install again. Existing credentials and usage history are preserved. Include the same --state-dir if customized. Setup and troubleshooting.
